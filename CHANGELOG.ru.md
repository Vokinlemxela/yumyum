# История изменений

[English](./CHANGELOG.md) · Русский

Все значимые изменения проекта Yum-yum Player.

## Ядро и транспорт WebRTC 1.2.0 — 2026-11-23

- Ядро подаёт кадры длинных сегментов живого HLS в декодер по времени воспроизведения. Это сохраняет равномерное движение, когда камера передаёт десять секунд видео одним сегментом.
- Скорость HLS оценивается по объёму и времени последних четырёх загруженных сегментов с отсечением единичных выбросов. Подтверждённые чтения из браузерного кэша исключаются. При ограничении сети плеер может снизить качество ещё при стабильной частоте кадров.
- В режиме Auto HLS учитывает потолок качества при первом запросе медиаплейлиста. При смене живого профиля ядро синхронизирует временную шкалу нового потока и освобождает кадры предыдущего.
- Для оценки нагрузки ядро использует частоту потока и ограничения отрисовки. Намеренные пропуски кадров при экономии ресурсов исключены из сигнала перегрузки. Экономичный режим восстанавливает настройки при выключении. Переполнение пула WebGL сохраняет выбранный режим Auto.
- При перегрузке отрисовки ядро выбирает поток меньшего разрешения. При нехватке полосы учитывает битрейт. Для WHEP приложение может перечислить доступные профили в `transportWebrtc({ qualityLevels })`. Потери входящих пакетов позволяют снизить качество. Для повышения нужны стабильный приём, оценка доступной полосы выбранной ICE-пары и известный битрейт следующего профиля.

## Ядро 1.1.2 — 2026-11-23

Плеер определяет AVC и HEVC по заголовку fMP4 и передаёт в WebCodecs профиль и параметры видеодорожки. Для HD-профилей камеры дополнительный поток определяется по меньшему разрешению, даже если его битрейт выше.

## 1.1.1 — 2026-11-22

Документация ядра и трёх плагинов теперь доступна на английском и русском языках. По умолчанию открывается английская версия.

## 1.1.0 — 2026-11-22

### Добавлено

- WebRTC/WHEP, WebSocket/RTSP и программный HEVC доступны как пакеты
  движка с открытым исходным кодом. Для подключения плагинов ключи не нужны.
- В комплект HEVC входят сборка libde265 1.1.3, исходники и лицензии
  сторонних компонентов, а также скрипт пересборки.

### Исправлено

- HLS-плеер разбирает fMP4-сегменты с `mdat` больше 5 МиБ, в том числе при
  загрузке частей сегмента. Оборванный сегмент больше не мешает разбору
  следующего. Для незавершённого `mdat` действует лимит 64 МиБ на буферизацию.

## 1.0.0 — 2026-06-29

Первый стабильный мажорный релиз. Включает адаптивное вещание, оптимизации рендеринга и повышенную отказоустойчивость.

### Добавлено
- **Адаптивный стриминг (ABR / Main-Sub)**: автоматическое и ручное переключение уровней качества на основе сетевой пропускной способности и производительности декодирования.
- **Ограничение плотности потока (Density Limit)**: потолок качества при воспроизведении нескольких окон/сеток для предотвращения перегрузки канала.
- **Отказоустойчивость и автоподключение (Реконнект 24/7)**: непрерывная работа плеера при разрывах соединений, автоматическое переподключение и восстановление декодеров без перезагрузки страницы.
- **Единые аудио-видео часы (A/V Clock)**: монотонная синхронизация звука и видео, привязанная к аппаратному времени аудиовыхода для плавного воспроизведения.
- **Мульти-камерный GPU-бюджет (WebGL Context Pooling)**: пул контекстов WebGL2 с автоматическим разжалованием неактивных плееров в 2D-режим для бесперебойного отображения больших видеостен (больше 8-16 камер).
- **События плеера**:
  - `qualitychange`: оповещение о переключении уровня качества.
  - `signals`: события состояния потока (отсутствие сигнала, восстановление, ошибки).
- **Метрики телеметрии**:
  - `renderMode`: текущий режим отрисовки (`webgl` или `canvas2d`).
  - `qualityMode`: текущий режим выбора качества (`auto` или `manual`).
